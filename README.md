# Transport Demo (Three.js)

Initial browser demo featuring:
- Scrollable isometric map
- Road building
- Road stations
- Road vehicles running between two stations
- Basic passenger queue + cash simulation

## Run

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Controls

- Left click: build road / place station / select stations for vehicle route
- Right mouse drag: pan camera
- Mouse wheel: zoom
